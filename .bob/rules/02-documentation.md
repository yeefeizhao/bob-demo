# Documentation

- Add a JSDoc or docstring comment to every exported function, class, and method.
- Keep comments concise — explain *why*, not *what* the code does.
- Update existing comments whenever the code they describe changes.
- Do not leave TODO or FIXME comments without a linked issue number (e.g. `// TODO #123: ...`).
- Every new module or package must include a brief top-of-file summary comment.
