# Coding Style

- Use 2 spaces for indentation in JavaScript, TypeScript, JSON, and YAML files.
- Use 4 spaces for indentation in Python files.
- Always use single quotes for strings in JavaScript and TypeScript unless the string contains a single quote.
- End every file with a single newline character.
- Limit line length to 100 characters.
- Remove trailing whitespace from all lines.
- Use `camelCase` for variable and function names, `PascalCase` for class and component names, and `UPPER_SNAKE_CASE` for constants.
