# Git Workflow

- Write commit messages in the imperative mood, starting with a capital letter (e.g. "Add login endpoint").
- Keep commits focused: one logical change per commit.
- Branch names must follow the pattern `<type>/<short-description>` (e.g. `feat/user-auth`, `fix/login-crash`).
- Never force-push to `main` or `develop`.
- Reference the relevant issue number in every commit message (e.g. "Fix null pointer in parser (#42)").
