# Testing

- Write at least one unit test for every new function or method introduced.
- Test file names must mirror the source file with a `.test` suffix (e.g. `utils.ts` → `utils.test.ts`).
- Each test must have a descriptive name that states the scenario and expected outcome.
- Do not commit code that causes existing tests to fail.
- Mock external services and I/O in unit tests; reserve integration tests for end-to-end flows.
